# TravelShaper — Running & Testing Guide

## Prerequisites

| Requirement | Version | Notes |
|-------------|---------|-------|
| Python | 3.11+ | Required |
| pip | Any recent | Comes with Python |
| Docker + Docker Compose | Any recent | For containerised run |
| OpenAI API key | — | Required for the agent |
| SerpAPI key | — | Required for flights/hotels/cultural guide |

## 1. Local Setup

### 1a. Clone / unzip the project

```bash
unzip travelshaper-complete.zip
cd travelshaper/se-interview-main
```

### 1b. Create and activate a virtual environment

```bash
python3 -m venv .venv
source .venv/bin/activate        # macOS / Linux
# .venv\Scripts\activate         # Windows
```

Your prompt should now show `(.venv)`. All subsequent commands assume the
venv is active.

### 1c. Install Poetry inside the venv

```bash
pip install --upgrade pip
pip install poetry==1.8.2
```

Poetry is now isolated to this venv and will not affect any system-wide
Python installation.

### 1d. Install project dependencies

```bash
# Runtime only
poetry install

# Or, with the test runner
poetry install -E dev
```

The Traceloop SDK (OpenLLMetry) and its LangChain auto-instrumentation are
declared in `pyproject.toml` and installed automatically. There are no
optional `phoenix`/`arize`/`custom` extras anymore — `poetry install` is
the simple path.

### 1e. Configure environment variables

```bash
cp .env.example .env
```

Open `.env` and fill in your keys:

```
OPENAI_API_KEY=sk-...
SERPAPI_API_KEY=...
TRACELOOP_BASE_URL=http://localhost:4318
```

`TRACELOOP_BASE_URL` points the Traceloop SDK at an OTLP/HTTP receiver. By
default that is the locally running **Observe Agent** on port 4318, which
forwards traces (and tailed structured logs) to Observe cloud. If no
collector is listening, the SDK simply drops spans — the app keeps running.

## 2. Running the API Server

### Option A — Local (venv)

```bash
uvicorn api:app --host 0.0.0.0 --port 8000 --reload
```

The API will be available at `http://localhost:8000`.

Verify it is healthy:

```bash
curl http://localhost:8000/health
# → {"status":"ok"}
```

Send a chat message:

```bash
curl -s -X POST http://localhost:8000/chat \
  -H "Content-Type: application/json" \
  -d '{"message": "Plan a trip from SFO to Tokyo in October. I want to save money and I love food."}'
```

### Option B — Docker Compose

`docker-compose.yml` now defines a single `travelshaper` service. The
Observe Agent is **not** part of the compose file — it runs on the host
and is managed by you (per Observe's install instructions). The container
bind-mounts `./logs:/app/logs` so the host-side Observe Agent can tail
the structured JSON log file written at `/app/logs/travelshaper.log`.

```bash
docker-compose up --build
```

| Service | URL |
|---------|-----|
| TravelShaper API | http://localhost:8000 |

Traces are exported via OTLP/HTTP to `TRACELOOP_BASE_URL` (default
`http://localhost:4318`, the host's Observe Agent) and surface in the
**Observe** UI — there is no local tracing UI to open.

Stop everything:

```bash
docker-compose down
```

### Option C — Docker only

```bash
docker build -t travelshaper .
docker run -p 8000:8000 --env-file .env travelshaper
```

## 3. Running the Tests

### Run the unit suite (recommended)

```bash
pytest tests/ -v
```

Expected output: the unit suite (~22-24 tests) covering agent structure,
API/validation, tool behaviour, and Traceloop initialisation.

> **No API keys are required to run tests.** All external calls are mocked.

### Run a specific test file

```bash
pytest tests/test_tools.py -v
pytest tests/test_agent.py -v
pytest tests/test_api.py -v
```

### Run a single test by name

```bash
pytest tests/test_tools.py::test_search_flights_formats_results -v
```

## 4. Generating Traces

Traces are generated by running real queries against the live API. With
the Observe Agent running on the host (listening on OTLP/HTTP `:4318`),
each request emits LangChain/LLM/tool spans via the Traceloop SDK.

### Run all 10 trace queries automatically

```bash
chmod +x run_traces.sh
./run_traces.sh
```

You can optionally pass a custom base URL:

```bash
./run_traces.sh http://localhost:8000
```

The script runs 10 queries covering every tool combination — flights,
hotels, cultural guide, DuckDuckGo search, budget vs. full-experience
mode, partial inputs, and edge cases. Each query is followed by a 2-second
pause to avoid rate limiting.

### Run a single query manually

```bash
curl -s -X POST http://localhost:8000/chat \
  -H "Content-Type: application/json" \
  -d '{"message": "What should I know before visiting Japan?"}'
```

Traces and tailed structured logs are forwarded by the Observe Agent to
**Observe cloud**; view them in your Observe workspace.

## 8. Troubleshooting

**`SERPAPI_API_KEY is not set` error**
The agent is running live (not in tests). Copy `.env.example` to `.env`
and add your SerpAPI key, then restart the server.

**`OPENAI_API_KEY` auth error**
Your OpenAI key is missing or invalid. Check your `.env` file.

**Tests fail to collect**
Make sure you are running from the project root (`se-interview-main/`) with
the venv active (`source .venv/bin/activate`). Then run `poetry run pytest tests/ -v`.

**No traces in Observe**
Traces are only generated when real queries hit the live API. Confirm the
**Observe Agent** is running on the host and listening on OTLP/HTTP
`:4318`, that `TRACELOOP_BASE_URL` matches, and then run
`./run_traces.sh` against the live server.

**No logs reaching Observe**
Check that `./logs/travelshaper.log` is being written (the app logs
structured JSON there) and that the Observe Agent is configured to tail
that file. In Docker, the host directory `./logs` is bind-mounted to
`/app/logs` inside the container.

**Poetry creates a nested virtualenv instead of using the active venv**
Run this once in the project directory, then reinstall:
```bash
poetry config virtualenvs.create false --local
poetry install
```

**Docker build fails at `poetry install`**
A `poetry.lock` file is required for reproducible builds. Generate it
with `poetry lock` and commit it before building the image.
